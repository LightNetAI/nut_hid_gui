📈 Data Flow: From UPS to Windows

1
UPS Reports Status
Physical UPS reports battery level, runtime, and status via USB or SNMP to NUT server
2
NUT Server Polls
upsd daemon polls UPS every 2-15 seconds, stores in shared memory
3
GUI/Driver Connects
nut_hid_driver connects to NUT server via TCP port 3493 using rups library
4
NUT Variables Queried
Driver queries: battery.charge, battery.runtime, ups.status, etc.
5
HID Reports Generated
Driver converts NUT data to HID Power Device Class reports (binary format)
6
HidBatt.sys Reads
Windows native HidBatt.sys driver reads HID reports via standard HID interface
7
Windows Power Management
Windows battery icon shows UPS status, triggers low-battery actions as configured
